04 / Motion language

Movement with purpose

Motion should make the brand feel tactile—not noisy. GSAP owns scroll choreography, Lenis owns scroll feel, and Framer Motion owns React UI states.

01

Scroll = GSAP

Use ScrollTrigger for pinning, parallax, image masks, storytelling and section choreography.

02

UI = Framer Motion

Use Motion for cart drawers, filters, modals, route transitions and state changes in the Next.js build.

03

Text = SplitType

Reserve character and line reveals for campaign headings. Product information stays immediate and readable.

04

Scroll feel = Lenis

Smooth desktop interpolation, with touch behavior kept native-feeling and accessible on mobile.

05

Respect reduced motion

Every decorative sequence has a low-motion fallback. Commerce actions never depend on animation.

06

Performance first

Animate transform and opacity, lazy-load media, and avoid stacking multiple animation engines on one property.
